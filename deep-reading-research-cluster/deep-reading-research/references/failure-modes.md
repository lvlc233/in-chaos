# Failure Modes

This module answers: what should the skill actively resist?

## Anti-patterns

- directory-name hallucination
- header hallucination
- example hallucination
- keyword skip-reading
- premature generalization
- conclusion before verification
- trigger-point loss
- uncertainty flattening
- decontextualization
- domain-noise contamination
- conclusion-only analysis

## Counter-rules

- names only create candidate explanations
- examples are not global rules
- keyword hits must return to context
- unresolved items stay unresolved
- every important claim keeps its trigger point
- field names do not explain lifecycle
