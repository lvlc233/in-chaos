# Implementation Playbooks

This module answers: how do we turn the terms into concrete action?

## Playbook: Gradual Reading

Input:

- a large corpus
- a target goal

Actions:

1. map files and regions
2. read one slice
3. restate what it says
4. log new questions
5. pick the next slice from the questions

Output:

- progress table
- current understanding
- new questions
- next step

## Playbook: Question Ledger

Input:

- a confusing concept or unresolved relation

Actions:

1. create a question row
2. assign a trigger point
3. assign a state
4. attach an answer snapshot
5. append evidence as it arrives

Output:

- question ledger entries
- relation table rows
- boundary notes

## Playbook: Evidence Judgment

Input:

- a candidate claim

Actions:

1. classify the source class
2. rank the evidence
3. record negative evidence
4. decide whether the claim is fact, inference, hypothesis, or noise
5. write the minimum confirmable conclusion

Output:

- evidence matrix
- conclusion level
- transfer boundary

## Playbook: Subagent Delegation

Input:

- a narrow uncertainty

Actions:

1. write a task sheet
2. define ownership
3. bound the search path
4. require direct and negative evidence
5. merge the result back into the main thread

Output:

- subagent report
- remaining uncertainty
- decision-ready synthesis

## Playbook: Skill Distillation

Input:

- reading logs
- question tables
- debugging records

Actions:

1. cluster repeated problems
2. keep the final fix and verification
3. extract behavior rules
4. drop noisy chronology
5. state migration boundaries

Output:

- reusable rules
- non-goals
- downstream interfaces
