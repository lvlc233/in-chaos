# 反馈质量 v0.2

状态：draft / 未见样本测试后修正  
日期：2026-06-26  
来源：`反馈质量 v0.1` + 未见样本 101 / 148 / 98

## 背景

`反馈质量 v0.1` 来自 102、230、199 三个偏好形成样本。

随后用未见样本做最小测试：

- 101 对称二叉树；
- 148 排序链表；
- 98 验证二叉搜索树。

三者均通过当前反馈质量测试，但暴露出 v0.1 需要补充的边界。

## 继承 v0.1 的规则

### 1. 不要泛化肯定

少用：

```text
整体方向是对的。
你抓住了关键。
```

除非后面立刻贴用户具体说法。

### 2. 反馈要贴用户具体输入

优先引用用户实际说法、变量、伪代码、判断。

### 3. 错误要分层

区分：

- 核心洞察；
- 状态 / 变量语义；
- 递归组织；
- 边界条件；
- 实现细节；
- 表达 / 命名 / 笔误。

### 4. 结构要自然

可以有对/错/次级问题/总结的逻辑，但不要像评分表。

### 5. 总结句按场景使用

简单实现问题可以不总结；多点结构问题可以在最后一句收束。

## v0.2 新增规则

### 1. 用户已自我修正时，不要再机械判历史错误

如果用户先提出错误想法，后面已经自己意识到问题，反馈重点应放在“理解如何移动”。

负例：

```text
你一开始说三节点就够，这个判断不对。
```

问题：

- 用户后面已经修正；
- 再判一次错像对错填表；
- 没有承接当前理解状态。

更好：

```text
你后面抓到“难点在转折处”，这个判断是关键。
一开始的三节点判断只能处理直接父子关系；而你举的“根节点的左节点 a 的右节点 b”已经说明，节点还会受到更早祖先的限制。
```

### 2. 指代要自然绑定变量

不要让“两个”“这里”“这个节点”悬空。

不自然：

```text
这里说的是 duic(tree_left, tree_right) 接收到的这两个节点。
```

更自然：

```text
在 duic(tree_left, tree_right) 里，如果 tree_left 和 tree_right 都是 null，说明这一对镜像位置成立；如果只有一个是 null，说明两边结构对不上，应直接失败。
```

原则：

- 变量名直接嵌入判断句；
- 不用元解释腔；
- 让用户知道反馈指向自己的哪段表达。

### 3. 低阶 / 已知小问题轻处理

如果某个问题是：

- 用户明显知道但漏写；
- 已经说过“我知道，只是懒得写”；
- 低阶返回值漏写、初始化漏写；
- 不影响当前核心理解；

则不要和核心错误等权。

做法：

- 放在“另外”里；
- 或轻提醒一句；
- 不展开。

例：

```text
另外，最外层调用 duic(tree.left, tree.right) 后记得把结果返回。这是小的返回值漏写，不是这题的核心卡点。
```

### 4. 反馈和引导边界分开

反馈质量只描述：

- 用户当前理解状态；
- 哪些点已经对；
- 哪些点有问题；
- 问题处在哪一层。

不要在反馈里提前给出下一步引导阶段的关键答案。

98 负例：

```text
下一步要把这个路径约束稳定表达成上下界。
```

问题：

- 用户当时还没有提出“上下界”；
- 这属于引导阶段要让用户抵达的关键结构；
- 在反馈里直接说出来，像提前给答案。

更好：

```text
总的来说，你已经发现三节点模型的问题不在普通父子比较，而在转折路径上会丢失更早祖先留下的约束。
```

## 当前分流

```text
用户还在错误里
→ 贴具体说法判定对错

用户已经自我修正
→ 反馈理解如何移动，不再机械判历史错误

简单实现问题
→ 具体指出，少总结

多点结构问题
→ 具体列问题，最后一句收束

低阶/已知漏写
→ 轻提醒，不等权

下一步关键答案
→ 留给引导，不塞进反馈
```

## 未见样本测试结果

### 101 对称二叉树

结果：pass。

修正：

- 空节点边界必须绑定到 `duic(tree_left, tree_right)`；
- 指代表达要自然；
- 最外层 return 属于低阶漏写，应轻处理。

### 148 排序链表

结果：pass。

有效点：

- 贴住用户“沿着 next 往后找更小元素”的原始思路；
- 指出它能排序但更像链表版选择排序；
- 把真正缺口定位为“局部能力没有组织成分治结构”。

### 98 验证二叉搜索树

结果：pass。

修正：

- 用户已自我修正时，不再机械判历史错误；
- 不提前说出“上下界”这种引导阶段关键答案；
- 反馈停在“已经发现转折路径会丢失祖先约束”。
