用户对 101 引导方向未见样本输出 B 做负向标注。

问题片段：

```text
当 tree_left 和 tree_right 都是 null 时，这一对镜像位置应该成立；
当只有一个是 null 时，结构已经不对称；
当两个都存在时，才需要继续比较值和递归子节点。
```

用户反馈：

- 这里感觉像是直接给用户答案；
- 不是引导。

含义：

- 对于引导方向测试，不能把关键边界条件直接列完整；
- 反馈阶段可以指出问题区域；
- 引导阶段应让用户自己判断这些情况，而不是直接给出每种情况的答案；
- 特别是“都为空/一个为空/都存在”的判断，是本题边界逻辑的核心。

待后续修正：

- 引导可以把注意力拉到入口判断；
- 可以说明为什么入口判断重要；
- 但不要直接填完三种情况的结果；
- 更好的方式是给一个具体小例子，让用户自己判定返回值。
