用户扩展关于 agent 交互模式的问题。

用户借用一句来自《三体》的改写：

> agent 内容（概念/问题）不断扩张，而人类回复有限。

核心问题：

- agent 会不断提出新概念、新问题、新分支；
- 但用户每次回复的精力、注意力和文本长度都是有限的；
- 因此问题会不断堆积；
- 用户的声音会越来越低，agent 的自发扩展会越来越强。

后果一：压力和未解决空间变大

- 不论 agent 提出的问题是否有价值，只要没有被处理，就会变成未解决空间；
- 未解决空间越大，用户心理压力越大；
- 用户需要同时背负已经出现但尚未回应的问题、分支和概念。

后果二：偏移效应与雪崩

- 当用户在某个环节拒绝回答、跳过、沉默或只回应部分内容时；
- 上下文中积累的未决定问题会影响 agent 后续判断；
- agent 会尝试自发补全、转向或继续推进；
- 这种自发偏移会进一步制造新问题；
- 新问题继续堆积，形成类似雪崩或链式反应的效应；
- 用户将越来越难把对话拉回自己的原始注意力轨道。

待后续整理成交互规则：

- agent 应限制同时打开的问题数量；
- 每次回复只维护一个主要焦点；
- 未解决问题不能无限悬挂；
- 如果用户跳过某问题，默认不继续追逐该问题，除非它是当前任务的硬阻塞；
- 避免让上下文中的旧问题自动驱动新偏移。
