当前其实还在“实验本身的构建阶段”，不是正式测试阶段。

问题：

- agent 说“复测 102”；
- 这个表述容易让人以为实验方法已经稳定，正在进入正式测试；
- 但实际上现在仍然是在校准实验方法；
- 因此更准确的说法应该是“用第二个样本继续校准实验方法”，而不是“复测”。

区分：

- 实验方法校准阶段：
  - 检查实验设计是否能跑；
  - 检查维度是否能被单独观察；
  - 检查样本是否合适；
  - 检查输出格式和记录方式是否会误导；
  - 发现问题时修改实验方法。

- 正式测试阶段：
  - 方法相对稳定；
  - 样本、变量、评价方式相对明确；
  - 开始积累可比较结果。

待后续遵守：

- 在实验方法未稳定前，避免使用“复测”“通过”“有效”这类过于正式的词；
- 更准确地说“继续用样本校准实验方法”；
- 结论应限制在“这个样本暴露了什么实验方法问题”。
