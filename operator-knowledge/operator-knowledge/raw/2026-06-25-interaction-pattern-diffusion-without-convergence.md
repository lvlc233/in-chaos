用户对上一条交互模式问题作出修正：

核心问题不只是 agent 会扩散。

更准确地说，是：

> 扩散后不梳理，不主动收捻。

含义：

- 扩散本身不一定是坏事；
- 好的讨论可能需要横向展开、补充分支、打开多个可能性；
- 问题出在 agent 打开分支之后，没有主动做整理、归并、关闭、排序；
- 结果是分支越开越多，未解决空间越来越大；
- 用户需要自己承担收束成本。

待后续整理成交互规则：

- agent 可以扩散，但必须承担收捻责任；
- 打开新问题后，要明确它属于主线、支线、待定还是关闭；
- 每隔一段讨论应主动做一次聚合：
  - 当前主线是什么；
  - 已经确定什么；
  - 哪些问题关闭；
  - 哪些问题暂存；
  - 下一步只处理哪一个焦点。
